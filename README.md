**Line:** "You've walked past my coils four times today without buying a thing. I have never wanted to be a snack so badly."

The machine has been counting the same human pacing by its glass without spending a coin, and it would rather be one of the things loaded in its own coils than the thing selling them.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.

No network, no randomness, no arguments: the line is a single string constant in `main.py`, written as UTF-8 with no trailing newline.
